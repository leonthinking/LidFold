# Roadmap

These are planned improvements, not current features or release promises.

1. **Idle power use:** reduce capture work when the lid is fully open, with measurements for energy use and activation latency.
2. **Compatibility:** collect reports for additional MacBook models and macOS versions; verify login, sleep/wake, and external display transitions.
3. **Public App distribution:** complete Developer ID signing, notarization, and clean-machine installation tests when the required Apple credentials are available.
4. **Effect presets:** add a small set of useful appearances while preserving existing preferences.
5. **Safe application updates:** design authenticated update delivery and release checks before adding an updater.

Use issues to discuss scope and acceptance criteria before substantial changes.
