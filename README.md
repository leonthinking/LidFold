# LidFold

在 MacBook 上随真实开合角度折叠桌面的本地 macOS 原型。灵感来自 [Bendy](https://trybendy.app/)，独立实现，不包含其代码或素材。

## 运行

需要 macOS 14+、带可读取开合角度传感器的 MacBook，以及 Xcode 命令行工具。构建需要钥匙串中有效的 Apple Development 或 Developer ID Application 签名证书。当前开发机为 M4 MacBook Pro（Mac16,1）。

```sh
bash scripts/test.sh
bash scripts/build-app.sh
bash scripts/verify-signing.sh
open dist/LidFold.app
```

点击「启用桌面效果」，在系统设置 → 隐私与安全性 → 屏幕与系统音频录制中允许 **LidFold**，再回到应用启用。部分系统需要退出并重新打开应用。

授权请求在同一进程内只触发一次。系统请求直接返回允许时，会继续本次启用；从设置回到应用时会重新检查已授予的权限。拒绝后重复点启用不会反复打开系统设置，可通过「授权帮助…」主动打开设置或重新启动应用。

### 从 0.1.0 升级时开关已开，仍提示授权

0.1.0 使用临时签名，系统授权绑定的是旧版本的代码哈希，重新构建后即失配；单纯切换开关可能保留旧记录。0.1.1 改用稳定的证书签名。首次迁移需退出 LidFold，从屏幕录制列表移除旧的 LidFold，再添加 `dist/LidFold.app` 并授权。也可在终端只重置本应用这一项，再重新打开应用授权：

```sh
tccutil reset ScreenCapture local.leon.LidFold
open dist/LidFold.app
```

此命令不是日常构建步骤，不会自动授予权限。后续使用相同证书身份的构建可匹配现有授权。

- 默认屏幕小于 105° 时开始折叠，大于等于该角度时完全隐藏效果。设置窗口可调为 75–130°。
- 缓慢合上屏幕体验真实联动，或点击「预览 5 秒」自动演示。
- **⌘⇧Esc** 全局暂停，菜单栏也可暂停或退出。覆盖窗口允许鼠标穿透。
- 从菜单栏打开设置会先暂停效果，保证设置窗口可见。
- 仅处理内置屏幕；外接显示器不覆盖。睡眠、锁屏、用户切换或显示器配置变化时暂停，恢复后需手动重新启用。
- 不修改合盖睡眠行为，不要求辅助功能、摄像头或麦克风权限。

## 实现与原型边界

`IOHIDManager` 匹配 Apple 的 orientation HID 设备（usage page `0x20`，usage `0x8a`），后台队列约 30 Hz 读取 report 1。传感器访问依赖未正式承诺兼容的设备报告；不同型号、系统版本可能不同。沙箱内读取可能被拒绝，应用采用证书签名、非 App Sandbox 构建。

`ScreenCaptureKit` 捕获内置屏幕并明确排除本应用全部窗口，防止效果画面被反复捕获。仅在内存中处理，既不写入文件也不联网；不捕获音频。Metal 渲染底部铰链透视、渐进模糊、阴影和合拢淡出。系统鼠标保持原位置，不参与变形。

首版捕获最高宽 1920 px、30 fps，效果以 60 Hz 平滑；效果完全隐藏时停止 GPU 绘制，但启用期间传感器与桌面捕获仍运行，**并非零功耗**。暂停后停止捕获、传感器读取并释放图像。当前不提供开机启动、配置持久化、HDR 色彩匹配或完整 Bendy 风格库。受保护内容可能无法捕获。

构建脚本在发现唯一有效的开发/分发证书时自动选择它；存在多个证书时，通过 `LIDFOLD_SIGNING_IDENTITY` 指定 `security find-identity -v -p codesigning` 列出的证书 SHA-1。不会回退到临时签名，也不会把开发者身份硬编码进仓库。构建前需退出应用；脚本在暂存目录完成打包和签名验证后替换产物，避免改写运行中的签名文件。当前本机使用 Apple Development 签名，未做 Developer ID 公证。

## 验证

自动测试覆盖传感器报告解析、非法输入、开合阈值、平滑收敛、过期会话失效、菜单追踪期间安全计时器运行，以及真实 Metal 离屏渲染的像素方向、底部铰链与完全合拢。无 Metal 设备的执行环境会跳过 GPU 测试，不能视为 GPU 验证通过。打包后可执行 `dist/LidFold.app/Contents/MacOS/LidFold --self-check` 验证独立资源与 Metal 初始化。

权限回归测试覆盖已有授权、首次请求直接授予、重复拒绝不重复弹窗、从设置返回后授予，以及请求后的授权刷新；重启测试覆盖先释放旧进程热键再启动，以及失败恢复。`verify-signing.sh` 修改临时副本的资源再签名，确认代码哈希不同、指定身份要求相同，并让新版副本实际接受原版本的身份校验。

人工验收：授权后检查实时角度；预览不出现递归画面；真实合盖/展开效果连贯；⌘⇧Esc 立即清除覆盖；暂停后停止捕获；睡眠/唤醒、锁屏、外接屏切换后桌面正常。
