# LidFold

[下载 v0.2.4](https://github.com/leonthinking/LidFold/releases/tag/v0.2.4) · [English](README.en.md) · [MIT License](LICENSE)

让 MacBook 的桌面随屏幕开合角度折叠。缓慢合上屏幕，桌面与应用画面逐渐变形；展开屏幕，画面恢复正常。

LidFold 是实验性的 macOS 菜单栏工具。画面仅在本机内存中处理，不保存、不上传，也不采集音频。

## 功能

- 真实开合角度联动，支持折叠、模糊和阴影。
- 调整开始折叠的角度与效果强度，设置立即保存。
- 五秒桌面预览，以及 **⌘⇧Esc** 紧急暂停。
- 登录时启动、启动时启用效果，以及唤醒后恢复选项。
- 原生 macOS 设置界面与菜单栏控制。

## 兼容性

| 项目 | 当前情况 |
| --- | --- |
| 最低部署目标 | macOS 14 |
| 下载包架构 | Apple Silicon（arm64），不支持 Intel |
| 已实测硬件 | M4 MacBook Pro（Mac16,1） |
| 已实测系统 | macOS 26.6.2 |
| 显示器 | 仅内置屏幕 |
| 其他 MacBook / 系统版本 | 尚未完成实机兼容性验证 |

需要能够读取开合角度的 MacBook。传感器报告并非 Apple 承诺跨机型兼容的接口，因此满足系统版本要求不代表一定支持。

## 获取与安装

下载即用，无需安装 Xcode 或自行构建：

1. 下载 [LidFold 0.2.4 DMG 安装包](https://github.com/leonthinking/LidFold/releases/download/v0.2.4/LidFold-0.2.4-arm64-unnotarized.dmg)，打开后将 **LidFold.app** 拖入 **Applications（应用程序）**，再推出磁盘映像。
2. 从「应用程序」打开 LidFold，按下方步骤授权并启用效果。启用登录自启后请避免移动 App。

也可下载 [ZIP 版](https://github.com/leonthinking/LidFold/releases/download/v0.2.4/LidFold-0.2.4-arm64-unnotarized.zip)，解压后将 App 移到「应用程序」。发行页附有 SHA-256 校验文件；其中 **Source code** 是源码，普通用户无需下载。

**当前安装包尚未经过 Apple 公证。** 首次打开若提示「无法验证开发者」或「Apple 无法检查是否包含恶意软件」，确认下载自本仓库后，进入 **系统设置 → 隐私与安全性**，在安全性区域点击 **「仍要打开」**，再按提示确认。见 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。此操作与屏幕录制授权是两步独立设置。

升级前先退出 LidFold，再替换 App。当前下载包使用 ad-hoc 签名；升级或从自行构建版切换时，可能需要重新允许打开并授权屏幕录制。若旧权限已开启仍反复提示授权，在系统的屏幕录制列表移除旧 LidFold，再用「+」添加「应用程序」中的新版本并授权，按提示重新打开。

开发者可参考 [构建指南](docs/DEVELOPMENT.md)。

## 首次授权与启用

1. 打开 LidFold，在「通用」中开启「启用桌面效果」。
2. 如果系统请求权限，打开 **系统设置（System Settings）→ 隐私与安全性（Privacy & Security）→ 屏幕与系统音频录制（Screen & System Audio Recording）**。部分系统显示为「屏幕录制」。
3. 允许 **LidFold** 录制屏幕。这个权限用于显示桌面效果，LidFold 不录制音频，也不保存画面。
4. 如 macOS 提示退出并重新打开，按提示操作；回到 LidFold，再开启「启用桌面效果」。
5. 默认低于 **105°** 时开始折叠，展开到该角度以上后恢复。也可在「效果」页点击「预览 5 秒」，预览结束会返回设置。

权限已开启但没有画面时，先退出并重新打开 LidFold，再检查是否仍在使用已授权的同一份 App。可通过「权限与关于 → 管理屏幕录制权限…」返回系统设置。自行构建时更换签名身份或 App 标识可能需要重新授权。

## 设置与操作

- **通用**：启用或暂停效果、查看实时角度、配置登录启动与唤醒恢复。
- **效果**：开始折叠角度可设为 75–130°，并调整模糊、阴影；恢复默认值只重置效果参数。
- **权限与关于**：查看权限、版本，以及重新打开应用。

「登录时启动」和「启动时启用效果」默认关闭，需分别开启。若 macOS 要求批准登录项，按应用提示进入 **系统设置 → 通用 → 登录项与扩展**；部分版本显示为「登录项」。自动启用只使用已有屏幕录制权限。

唤醒恢复默认开启，只恢复此前启用的效果；手动暂停后保持暂停。登录启动时安静驻留菜单栏。通过菜单栏「设置…」或 **⌘,** 打开设置，按 **⌘⇧Esc** 或使用菜单栏暂停效果。

LidFold 自己的设置窗口不参与折叠，方便随时调整；浏览器、访达等其他应用画面随桌面一起变化。预览会暂时收起设置窗口。

## 隐私与使用限制

- 桌面捕获仅在本机内存处理；不保存、不上传，不联网，也不采集音频。
- 不需要辅助功能、摄像头或麦克风权限，不改变 MacBook 的合盖睡眠行为。
- 变形的是屏幕画面，真实窗口和鼠标点击位置不会跟随变形；正常操作前请展开屏幕或暂停效果。
- 受保护内容可能无法显示；尚未提供 HDR 色彩匹配。
- 启用期间仍有传感器和桌面捕获开销，不是零功耗。暂停后停止捕获与传感器读取。
- 真实登录启动、睡眠/唤醒、锁屏/解锁和多显示器切换仍需更广泛实机测试。
